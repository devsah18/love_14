# 🎂 Birthday Proposal Website ❤️

A simple, elegant, and interactive birthday surprise website created for someone special.

The website combines a birthday card, interactive gift, friendship memories, a personal letter, and a romantic proposal into one mobile-friendly experience.

## ✨ Features

* 🎂 Interactive birthday surprise
* 🎁 Animated gift reveal
* 💌 Personal birthday message
* 🕰️ Friendship story timeline
* ✨ Animated background particles
* ❤️ Romantic proposal section
* 📱 Fully responsive mobile design
* 🎨 Elegant dark and minimal design
* ⚡ Pure HTML, CSS, and JavaScript
* 🆓 Completely free to host
* 🚀 GitHub Pages compatible
* 🔒 No backend or database required

## ✏️ Personalization

Open `script.js` and find:

```javascript
const CONFIG = {

    herName: "Her Name",

    yourName: "Your Name",

};
```

Replace the values with your own names:

```javascript
const CONFIG = {

    herName: "Her Name",

    yourName: "Your Name",

};
```

You can also edit the messages directly inside `index.html` to make the website more personal.

## 🚀 Deploy on GitHub Pages

### 1. Create a repository

Create a new GitHub repository.

Example:

```text
birthday-proposal
```

### 2. Upload the files

Upload:

```text
index.html
style.css
script.js
README.md
```

Make sure these files are in the **root** of the repository.

### 3. Enable GitHub Pages

Go to:

**Repository → Settings → Pages**

Under **Build and deployment**:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Click **Save**.

### 4. Open your website

After GitHub finishes deploying, your website will normally be available at:

```text
https://YOUR-USERNAME.github.io/birthday-proposal/
```

For example:

```text
https://devsah18.github.io/birthday-proposal/
```

## ⚠️ Privacy

This project is intended as a personal birthday surprise.

If you add personal photos, memories, or private information, remember that a GitHub Pages website is publicly accessible.

Avoid adding:

* Phone numbers
* Addresses
* Passwords
* Private conversations
* Sensitive personal information
